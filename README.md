MOTHLIGHT is a top-down 2D stealth game: you are a moth-thief sneaking through three wings of a night museum. Slip past patrolling watchmen and their lantern cones, hide in shadows and behind crates, steal every glowing moon-moth, and reach the green exit unseen. Watch the detection meter, throw pebbles to lure guards away, and go for a ghost run — never raising the alarm.

## Run it

```sh
python3 -m http.server 8000 --directory game
# open http://localhost:8000 in a desktop browser
```
